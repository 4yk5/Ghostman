## Reporting a Vulnerability

Security is paramount for local-first developer tools. If you discover a security vulnerability within Ghostman:

1. **Do not disclose publicly** in an open issue.
2. Please report security issues privately via GitHub Security Advisories or reach out directly to the maintainer.
3. Include detailed steps to reproduce the vulnerability.

We take all security reports seriously and will investigate, patch, and release a fix promptly.
